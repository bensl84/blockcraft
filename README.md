# Blockcraft

Blockcraft is an original, Minecraft-style block-building game for a young child, playable in a web browser on a laptop or touchscreen.

[Play Blockcraft](https://bensl84.github.io/blockcraft/)

- One self-contained `index.html`: it works from this website, offline after the first visit, or opened straight from a downloaded copy.
- All art, sounds and music are generated by the game's own code. No Mojang assets are used, and the game is not affiliated with Mojang or Microsoft.
- No accounts, chat, ads or data collection. Worlds save in the browser on the device.

## For grown-ups

New worlds start in Creative mode with no monsters, no fall damage, a Home button and Undo. Survival worlds (health, hunger, crafting, monsters at night) are a picture card away. Settings sit behind a grown-up gate.

## Development

`npm install`, then `npm run build` (writes `index.html`), `npm test` (automated playtest in headless Chrome) and `npm run test:unit`. The full specification is in [docs/SPEC.md](docs/SPEC.md).
